## 🎨 Customizing The Theme

The main colors are controlled through CSS variables in `style.css`.

For example:

```css
:root {
    --primary: #2563eb;
    --primary-dark: #1d4ed8;
    --text: #111827;
    --background: #ffffff;
}
```

Changing these variables allows the overall color scheme of the portfolio to be modified easily.

---

## 🌙 Dark Mode

The website includes a built-in dark mode.

The theme is controlled through JavaScript and stored using the browser's Local Storage API.

The selected theme remains active when the user returns to the website.

## 🚀 Deployment

Since this is a static HTML/CSS/JavaScript project, it can be deployed using:

* GitHub Pages
* Netlify
* Vercel
* Cloudflare Pages

### GitHub Pages

To deploy through GitHub Pages:

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose the deployment branch.
6. Save the configuration.
7. GitHub will generate the public website URL.
